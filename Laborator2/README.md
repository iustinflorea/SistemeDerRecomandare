# Laborator 2 - Recombee

## Set de date
- Dataset: Adidas vs Nike (https://www.kaggle.com/datasets/kaushiksuresh147/adidas-vs-nike/data)
- Volum: 3.268 produse
- Proprietăți: product_name (string), listing_price (int), sale_price (int), discount (int), brand (string), description (string), rating (double), reviews (int), last_visited (timestamp)

## Continut repository
- `AdidasVsNike.csv` - fisierul cu date
- `recombee_properties.py` - scriptul Python pentru trimiterea proprietatilor
- `requirements.txt` - librariile necesare

## Justificare alegere set de date
Am ales acest set de date deoarece provine din domeniul e-commerce, este curat, usor de prelucrat si ofera suficiente produse si atribute diverse pentru a testa eficient functionalitatile platformei Recombee.
